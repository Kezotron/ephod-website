Set the verse for this week

How it works

  1. The page opens on next week, which is the week you usually set. Change the week at the top if you need to fix the current one.
  2. Choose the book, chapter and first verse. If the verse runs over several verses, choose the last verse too; leave it at "single verse" otherwise.
  3. Preview if you like, then press Update memory verse. The box at the top shows what the website and the apps will display.

Example: John 3:16 → John, 3, 16, single verse. Psalms 103:11–12 → Psalms, 103, 11, 12.
