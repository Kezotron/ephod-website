Each week

  1. Type the title and set the date (it starts on the coming Sunday).
  2. Type the reading reference, for example Isaiah 36:1 through 38:22.
  3. Paste the devotion text. Mark the Scripture quotation with Scripture quote.
  4. Add a photo if you have one, then press Publish. It appears on the website right away.

To fix something later, click the devotion in the list, make the change, and press Publish again.
